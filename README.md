# Dancing Queen

A small Swedish practice site for Arianna, built by her sister Juliette. ABBA on the radio, a disco ball named Glittra, and a cartoon Arianna in a gold jumpsuit and platform boots.

Flashcards by planet (idioms, news and society, work and emails, feelings, Stockholm, nature and seasons, ABBA), a ten-question quiz with a grammar bank, a verb drill across presens, preteritum, perfekt and futurum, real-life phrases, Swedish audio, and five games: dress Arianna in stage outfits, prices in kronor, en/ett/plural adjective agreement, build the sentence, and pairs.

Content sits around B2 by default (Lagom), with a B1 review setting and a C1 stretch setting. Progress is stored in the browser only.

Plain HTML, CSS and JavaScript. No build step. `data.js` holds all the content. Fonts are bundled in `fonts/` so it works offline. Open `index.html` or serve the folder.

Sister site of Le Petit Observatoire, the French one.
